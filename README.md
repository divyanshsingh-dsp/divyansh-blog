# Divyansh Writes — Personal Blog

A responsive, static personal blog for GitHub Pages.

## Publish it with GitHub Pages
1. Create a new **public** GitHub repository named `divyansh-blog` (or another name you prefer).
2. Upload `index.html` from this folder to the repository root and commit it to the `main` branch.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main**, folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to finish publishing. The URL will be:
   `https://divyansh-singh-dsp.github.io/divyansh-blog/`

If your GitHub username is different, replace it in the URL with your exact username.

## Customize
Edit the article content and profile links in `index.html`. Do not publish API keys, passwords, or other secrets.
